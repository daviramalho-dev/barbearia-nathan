# Barbearia Natanael

Sistema web para gerenciamento de uma barbearia, desenvolvido para centralizar agendamentos, serviços, profissionais, produtos e informações administrativas.

## Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Java
- Spring Boot
- Spring Data JPA

### Banco de dados
- PostgreSQL
- Neon

## Estrutura

- `frontend/` — aplicação web
- `backend/` — API REST e regras de negócio
